# Práctica: Método de Gauss

## Datos de la práctica

- **Asignatura:** SCC-1017 Métodos Numéricos
- **Unidad:** 3
- **Práctica:** Método de Gauss
- **Lenguaje de programación:** Java
- **Paradigma:** Diseño modular

## Descripción

Este proyecto implementa el método de eliminación de Gauss para resolver un sistema de ecuaciones lineales.

El programa está organizado de manera modular en tres clases:

- `defMatrizz.java`: contiene la matriz aumentada del sistema.
- `gauss.java`: contiene la lógica para realizar la eliminación gaussiana y la sustitución regresiva.
- `lanzadorGauss.java`: contiene el método `main` y ejecuta el programa.
